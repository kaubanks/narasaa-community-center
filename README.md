# Narasaa Community Center

Official website for Narasaa Community Center in Tanzania.

## About

Narasaa Community Center supports education, clean water, community development,
women's empowerment, cultural activities, and wildlife conservation.

## Technologies

- HTML5
- CSS3
- JavaScript
- Formspree

## Project Structure

- `index.html` — Homepage
- `about.html` — About Narasaa
- `education.html` — Education programs
- `borehole.html` — Clean water project
- `cultural-tour.html` — Cultural tourism
- `safari.html` — Safari partnership
- `contact.html` — Contact/volunteer page
- `css/` — Stylesheets
- `js/` — JavaScript
- `images/` — Website images
- `assets/` — Additional assets
